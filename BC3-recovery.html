BC3 Wallet Recovery

Turns your seed phrase into the exact commands BitcoinIII Core needs. Everything happens in this file, on this machine.

This file never sends anything anywhere. It has no network code at all — you can disconnect and it works the same. Still, type your seed phrase only into a copy you downloaded yourself, and never into a website that asks for it.
